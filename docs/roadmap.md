# GearFlow 交付计划

## 第一阶段：日常业务闭环（本轮）

- 客户、供应商档案：新增、编辑、查询，往来金额与单据统计。
- 单据：采购/销售草稿、继续编辑、确认记账、详情查看。
- 库存盘点：录入实盘数和原因，预览差异，确认后原子更新库存与流水。
- 交互：加载骨架、库存变化高亮、抽屉切换和保存反馈，尊重减少动画设置。
- 验收：草稿不影响库存；重复确认不重复扣库存；盘点遇到库存变化拒绝覆盖；旧数据保留。

## 第二阶段：正式使用基础

基础管理员登录已完成（密码散列、会话保持、退出与业务接口保护）。待完成：角色权限、多企业隔离、PostgreSQL 迁移、多仓库与调拨、审计日志。
验收重点：企业间不可越权访问，关键操作有记录，数据库可备份恢复。

## 第三阶段：业务扩展与交付

采购/销售退货、单据冲销、序列号、真实成本核算、统计报表、扫码盘点、部署与课程材料。
按课程要求建立用例、查询统计和报表清单，补 UML、数据库设计、技术选型、演示 PPT。

当前仍为本机单工作区体验，尚未完成多租户或上线部署。登录与演示数据说明见 `login-and-demo.md`。

第一阶段已落地；已添加后端事务测试及浏览器闭环测试，覆盖客户建档、草稿不改库存、重复确认、盘点冲突、重启持久化和手机抽屉。
